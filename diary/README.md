# Effort diary (RQ4)

One row per work session, written the same day. Log the real date and real active minutes, not the planned ones: this file is research data.

| Column | Meaning |
|---|---|
| date | YYYY-MM-DD |
| start, end | HH:MM |
| active_minutes | time actually spent on the task (breaks excluded) |
| configuration | Baseline, Restricted, Prototype or all |
| category | shared, local-permission, network-restriction or OPA |
| task | short description |
| task_order | running number of this task type (to see learning effects) |
| revisions | how many config/code revisions the task needed |
| faults | what broke, or none |
| learning_notes | what was new or had to be looked up |
| git_commit | commit hash that holds the result |

Fixed changes for RQ4 (grant removal/restoration, one added user/resource permission) get their own rows per configuration.
